# 청각장애인 가정용 위험 상황 감지 시스템 v7 (졸업작품)

**프로젝트 정의**: 기존 청각장애인 보조기기(화재경보 스트로브, 초인종 점멸등, 아기울음 감지기 —
정부 지원 6종)가 커버하지 **못하는** 가정 내 위험 — **낙상, 침입(유리 깨짐), 비명** — 을
소리로 감지해 시각·진동으로 알린다.

## 최종 성능 (테스트 754개, 데이터 누수 없는 그룹 단위 분리)

| 항목 | 목표 | 달성 |
|---|---|---|
| 아기 울음 F1 | ≥ 0.90 | **0.978** |
| 유리 깨짐 F1 | ≥ 0.90 | **1.000** |
| 문 소리 Precision | ≥ 0.90 | **1.000** |
| **낙상 Recall** | ≥ 0.90 | **0.929** |
| 전체 정확도 (6클래스) | ≥ 92% | **92.7%** |

참고: 5클래스(v6) 정확도 96.5%. 6클래스 수치가 낮은 이유는 (1) 테스트 배경에 SAFE 비낙상
'쿵' 소리 95개가 추가된 어려운 시험이고 (2) 낙상 recall을 위해 오탐을 의도적으로 감수했기 때문.
SAFE 원논문(이진 분류)이 93%였음을 감안하면 6클래스에서 동등 이상.

## 모델 구조 (논문/발표용 요약)

1. **특징**: YAMNet(AudioSet 200만 클립 사전학습) 임베딩 평균 1024 + 521클래스 점수 max 521 = 1545차원
2. **분류기**: MLP 3시드(하드 네거티브 마이닝 ×4 재학습) 확률 평균 ⊕ HistGradientBoosting = 앙상블
3. **결정 규칙**(검증셋에서 자동 튜닝): 낙상 확률 부스트(놓침 방지) + 유리/문 임계값 τ(오탐 방지)
4. **핵심 기법**:
   - 데이터 누수 없는 그룹 단위 분리 (ESC-50 fold / 아기 UUID / SAFE 녹음설정)
   - "조용한 낙상" 증강 (게인 0.3x, 배경 믹싱) → 낙상 recall 0.85→0.93
   - 비낙상 '쿵' 소리를 배경 하드 네거티브로 사용 → "쿵 = 낙상" 오학습 방지
